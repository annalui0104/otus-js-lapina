## Тестовые сценарии для приложения «Параграфы»

### 1. Кнопка скрыта при первоначальной загрузке страницы

**Подготовка:** Открыть страницу. Поле ввода пустое.
**Действие:** Ничего не вводить в поле.
**Проверка:** Кнопка добавления параграфа не отображается.

### 2. На странице изначально отображаются три параграфа

**Подготовка:** Открыть страницу.
**Действие:** Просмотреть список параграфов.
**Проверка:** На странице отображаются ровно три текстовых параграфа.

### 3. Кнопка появляется после ввода текста

**Подготовка:** Открыть страницу с пустым полем ввода.
**Действие:** Ввести в поле текст `Новый параграф`.
**Проверка:** Кнопка добавления становится видимой.

### 4. Кнопка снова скрывается после очистки поля

**Подготовка:** Ввести текст в поле ввода, чтобы кнопка появилась.
**Действие:** Удалить весь текст из поля.
**Проверка:** Кнопка снова скрывается.

### 5. После нажатия кнопки добавляется новый параграф

**Подготовка:** На странице находятся три исходных параграфа. В поле введено `Новый параграф`.
**Действие:** Нажать кнопку добавления.
**Проверка:** На странице становится четыре параграфа.

### 6. Новый параграф содержит текст из поля ввода

**Подготовка:** В поле ввода ввести `Привет, мир!`.
**Действие:** Нажать кнопку добавления.
**Проверка:** Последний добавленный параграф содержит текст `Привет, мир!`.

### 7. Новый параграф добавляется после существующих

**Подготовка:** На странице находятся три исходных параграфа. В поле введено `Четвертый параграф`.
**Действие:** Нажать кнопку добавления.
**Проверка:** Новый параграф отображается после трех первоначальных параграфов.

### 8. При добавлении четвертого параграфа первый не удаляется

**Подготовка:** На странице находятся три исходных параграфа.
**Действие:** Ввести текст и добавить еще один параграф.
**Проверка:** На странице находятся четыре параграфа, включая первый исходный параграф.

### 9. При появлении пятого параграфа первый удаляется

**Подготовка:** На странице находятся четыре параграфа.
**Действие:** Ввести текст `Пятый параграф` и нажать кнопку добавления.
**Проверка:** Первый из ранее отображавшихся параграфов удален, а общее количество параграфов остается равным четырем.

### 10. После удаления первого параграфа остальные сохраняют порядок

**Подготовка:** На странице находятся четыре параграфа: `Первый`, `Второй`, `Третий`, `Четвертый`.
**Действие:** Добавить параграф `Пятый`.
**Проверка:** На странице отображаются `Второй`, `Третий`, `Четвертый`, `Пятый` именно в таком порядке.

### 11. При каждом последующем добавлении удаляется самый старый параграф

**Подготовка:** На странице находятся четыре параграфа.
**Действие:** Последовательно добавить еще два новых параграфа.
**Проверка:** После каждого добавления количество параграфов остается равным четырем, а удаляется самый первый из отображавшихся до добавления.

### 12. Количество параграфов после многократного добавления не превышает четырех

**Подготовка:** Открыть страницу с тремя исходными параграфами.
**Действие:** Добавить десять новых параграфов.
**Проверка:** После завершения всех действий на странице отображается ровно четыре параграфа.

### 13. Можно добавить параграф из одного символа

**Подготовка:** Поле ввода пустое.
**Действие:** Ввести `A` и нажать кнопку.
**Проверка:** Появляется новый параграф с текстом `A`.

### 14. Можно добавить текст с пробелами между словами

**Подготовка:** Поле ввода пустое.
**Действие:** Ввести `Это новый параграф` и нажать кнопку.
**Проверка:** Добавленный параграф содержит полный текст `Это новый параграф`, включая пробелы между словами.

### 15. Можно добавить текст со специальными символами

**Подготовка:** Поле ввода пустое.
**Действие:** Ввести `Hello, world! #2026` и нажать кнопку.
**Проверка:** Новый параграф содержит строку `Hello, world! #2026` без изменений.

### 16. Можно добавить текст на русском языке

**Подготовка:** Поле ввода пустое.
**Действие:** Ввести `Новый текст на русском языке` и нажать кнопку.
**Проверка:** Новый параграф содержит введенный русский текст без изменений.

### 17. Новый добавленный текст участвует в дальнейшем удалении старых параграфов

**Подготовка:** Добавлять параграфы до тех пор, пока первоначальные три параграфа не будут удалены.
**Действие:** Добавить еще один параграф.
**Проверка:** Удаляется самый старый из ранее добавленных пользователем параграфов, а новый остается последним.
